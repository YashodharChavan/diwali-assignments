# Deep Equality:
- We need to create a function which will tell if `values` of two parameters are equal. 
- we will have permutation of the following datatypes for two parameters.  

## Should support datatypes:
- Boolean
- Integer
- String
- Array (plain)
- Array (nested)
- Object (plain)
- Object (nested)
- NaN
- Undefined
- null
